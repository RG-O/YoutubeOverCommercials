# Plugin Templates

There are currently three different plugin templates. Pick one that fits your needs!

## Trigger Plugin

This can be used to indicate if a program is in commercial break or not.

- [Python WebSocket Trigger Template](trigger-websocket/python-template) 

## Overlay Plugin

These can be used to do something when the extension indicates that it is a commercial break.

- [Python WebSocket Overlay Template](overlay-websocket/python-template) 
- [Python API Overlay Template](overlay-api/python-template)
